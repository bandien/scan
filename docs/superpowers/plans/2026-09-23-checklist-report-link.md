# Kế hoạch thêm liên kết báo cáo

1. Thêm test Playwright tại `tests/nhatky-report-link.spec.js`; chạy để xác nhận RED vì liên kết chưa tồn tại.
2. Thêm liên kết có ID ổn định vào header của `nhatky/index.html`.
3. Chạy lại test mục tiêu trên desktop và mobile.
4. Chạy bộ test liên quan đến trang Nhật ký để kiểm tra hồi quy.
5. Bổ sung liên kết báo cáo Hapulico riêng và kiểm thử URL/thuộc tính an toàn trên desktop, mobile.
