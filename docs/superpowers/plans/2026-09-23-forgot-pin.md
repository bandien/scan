# Kế hoạch triển khai chức năng quên mã PIN

1. Thêm Playwright test cho việc mở, nội dung bảo mật, liên kết email và đóng modal; xác nhận không còn liên kết gọi điện/SMS.
2. Thêm nút `Quên mã PIN?` vào form đăng nhập.
3. Thêm modal khôi phục và hàm mở/đóng, sử dụng tài khoản đang chọn.
4. Chạy test trên desktop và mobile, sau đó kiểm tra hồi quy đăng nhập.
5. Commit, push và xác minh GitHub Pages.
