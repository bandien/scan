# Kế hoạch triển khai

1. Thêm `tests/timer-list-dialog.spec.js` xác nhận dashboard gọn, cửa sổ ẩn mặc định, mở đúng bảng, tìm kiếm và đóng; chạy RED.
2. Sửa `nhatky/index.html`: thêm hai thẻ tóm tắt, cửa sổ danh sách và tìm kiếm; dựng bảng theo yêu cầu thay vì khi tải dashboard.
3. Điều chỉnh kiểm thử nguồn để mở cửa sổ trước khi đối chiếu dữ liệu.
4. Chạy các kiểm thử hẹn giờ trên desktop và mobile, kiểm tra ảnh giao diện và `git diff --check`.
